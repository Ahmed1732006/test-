IN THE VOID — أزرار الروابط السريعة

1) نفّذ ملف IN_THE_VOID_PLATFORM_BUTTONS.sql مرة واحدة داخل Supabase SQL Editor.
2) بعد التنفيذ افتح الموقع كأدمن.
3) افتح «ملك المنصة» ثم قسم «أزرار الروابط السريعة».
4) ستجد واتساب وتليجرام جاهزين ويمكن تعديلهما بالكامل.
5) «إضافة زر جديد» يتيح زرًا مخصصًا: اسم + لون + أيقونة + رابط + صورة أو GIF + الجمهور + وقت الظهور/الاختفاء + تشغيل/إخفاء.
6) التعديل لا يحتاج تعديل أي Theme؛ كل السمات تستخدم app/index.html الموحد.
7) تم نسخ 1.png إلى app/1.png حتى تظهر أيقونة الموقع داخل كل السمات.

ملاحظة: رابط الزر نفسه لازم يبدأ بـ http:// أو https://.
